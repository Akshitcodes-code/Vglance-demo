# vGlance - Semantic Search Engine for Short-Form Videos
**Team ID:** [Your Team ID]

## 🚀 Project Overview
vGlance is an AI-powered semantic search engine designed for Instagram Reels and YouTube Shorts. Unlike traditional search engines that rely only on hashtags and titles, vGlance uses Multimodal AI to understand the actual video content.
- **Speech-to-Text:** Transcribes spoken dialogue using OpenAI Whisper.
- **OCR:** Detects on-screen text overlays using EasyOCR.
- **Caching:** Saves processed transcripts to PostgreSQL for instant future searches.

## 🛠️ Technologies Used
- **Backend:** FastAPI (Python)
- **AI Models:** OpenAI Whisper (Audio), EasyOCR (Text)
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **Data Retrieval:** YouTube Data API v3, yt-dlp
